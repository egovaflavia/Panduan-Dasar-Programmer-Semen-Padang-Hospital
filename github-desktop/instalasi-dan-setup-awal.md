# Instalasi dan Setup Awal

#### Langkah-langkah:

1. Unduh dari [https://desktop.github.com](https://desktop.github.com)
2. Install dan buka aplikasi GitHub Desktop.
3. Login menggunakan akun GitHub.
4. Atur informasi Git:
   * **File > Options > Git**
   * Isi nama dan email (sesuai akun GitHub).
