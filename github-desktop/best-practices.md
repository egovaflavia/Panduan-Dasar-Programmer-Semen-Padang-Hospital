# Best Practices

✅ Selalu:

* Buat branch baru untuk setiap fitur atau bug.
* Pull sebelum mulai kerja (`Fetch origin` + `Pull origin`).
* Tulis commit message yang deskriptif.
* Gunakan `.gitignore` untuk mengecualikan file tidak penting.

❌ Hindari:

* Kerja langsung di `main` atau `develop`.
* Commit file build, log, atau `node_modules`.
* Membuat PR tanpa deskripsi.
