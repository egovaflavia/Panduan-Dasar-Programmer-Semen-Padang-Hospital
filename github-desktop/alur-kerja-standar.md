# Alur Kerja Standar

#### Clone Repository

* Pilih **File > Clone Repository**.
* Masukkan URL repo atau pilih dari daftar.

#### Membuat Branch Baru

* Klik `Current Branch > New Branch`
* Gunakan penamaan sesuai standar
* Branch baru otomatis berpindah saat dibuat

#### Commit Perubahan

* Setelah melakukan perubahan file:
  1. Masukkan pesan singkat & deskriptif di "Summary"
  2. Klik `Commit to [branch_name]`

> 💡 Gunakan format pesan commit:\
> `feat: menambahkan validasi email`

#### Push ke GitHub

* Klik `Push origin` untuk mengirim commit ke remote.

#### Membuat Pull Request (PR)

* Klik `View on GitHub` di kanan atas.
* Klik “New Pull Request”
* Pilih branch asal & target (`feature/xyz → develop`)
* Tambahkan deskripsi PR
* Assign reviewer (jika ada)
