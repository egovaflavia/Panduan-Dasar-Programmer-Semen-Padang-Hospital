# Struktur Branch

Gunakan struktur branch berikut:

| Jenis Branch | Tujuan                 | Format Penamaan      |
| ------------ | ---------------------- | -------------------- |
| `main`       | Produksi               | -                    |
| `develop`    | Integrasi pengembangan | -                    |
| `feature/`   | Fitur baru             | `feature/nama-fitur` |
| `bugfix/`    | Perbaikan bug          | `bugfix/nama-bug`    |
| `hotfix/`    | Perbaikan darurat      | `hotfix/nama-hotfix` |

> **Contoh:** `feature/login-form`, `bugfix/validasi-email`
