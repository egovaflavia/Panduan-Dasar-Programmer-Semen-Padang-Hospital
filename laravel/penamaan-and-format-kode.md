# Penamaan & Format Kode

| Elemen         | Format             | Contoh                                  |
| -------------- | ------------------ | --------------------------------------- |
| Model          | PascalCase         | `UserProfile`                           |
| Controller     | PascalCase         | `UserProfileController`                 |
| Method         | camelCase          | `getUserProfile()`                      |
| Variabel       | camelCase          | `$userProfile`                          |
| Table DB       | snake\_case plural | `user_profiles`                         |
| Field DB       | snake\_case        | `created_at`                            |
| Route name     | kebab-case         | `user-profile.index`                    |
| Migration file | snake\_case        | `2023_01_01_create_user_profiles_table` |
